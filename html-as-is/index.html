A page that styles itself

This file is published byte for byte. Nothing on this page was rendered, wrapped in the site's shell, or styled by the site's stylesheet — what you are reading is the file as it sits in the vault.

Four ways to style a page, all of them kept

  1. A separate stylesheet: the type on this page comes from styles.css.
  2. A <style> block: this panel's border and radius.
  3. A url() in that block: the panel's background texture.
  4. A style attribute: the heading's letter-spacing, and the circle below.

Links, and which ones work

  • A second page in a subfolder — another file published as-is. The folder structure is mirrored, so this link needs no rewriting and the build report says nothing about it.
  • A link written to a note's Markdown — deliberately wrong. A note is published as its .html page, never as source, so this one cannot resolve. Look for it by name in the build report, which says where to point it instead.
  • An external link — left exactly as written, like every absolute URL.
